# Food Tracker Component

## Features

- **Search for food items**: Allows users to search for food by name using the USDA API.
- **Track foods**: Users can add foods to a tracker list to monitor their nutritional content.
- **Nutrient breakdown**: Displays macronutrient information (protein, fat, carbs, fiber, sugars) for each food item.
- **Interactive graph**: A bar chart visualizing the macronutrient breakdown for all tracked foods.
- **Statistical overview**: A section showing total calories, fats, proteins, carbs, and fiber for all tracked foods.
- **Remove foods**: Users can remove foods from the tracker and update the graph accordingly.
- **Clear tracker**: Clears all tracked foods and resets the nutritional data.

## Built With

- **React**: Front-end framework for building the user interface.
- **USDA API**: Provides nutritional data for various foods.
- **Chart.js**: Used for rendering the macronutrient bar chart.
- **HTML, CSS**: For structuring and styling the app's interface.
